# Privacy & Ethical Boundaries

CellScope is an observability tool designed to help users understand their personal network environment. **It is NOT a carrier surveillance application.**

---

## Explicit Prohibitions & Guarantees

- **NO Call/SMS Interception**: Does not access voice or message communications.
- **NO Traffic Capture**: Does not inspect payload packets or decrypt cellular traffic.
- **NO Subscriber Identification**: Does not access platform-restricted identifiers without explicit user permissions.
- **NO Invasive Network Scanning**: Local network discovery is confined strictly to safe ARP cache inspection, ICMP ping, and mDNS/reverse DNS queries on the user's subnet.
- **Granular Data Erasure**: Users can permanently delete their cellular snapshots, location trails, or local network device history with a single click.
