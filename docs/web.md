# CellScope Web Application

The web interface is built with **ASP.NET Core Blazor (Interactive Server)**, delivering a high-performance Network Operations Center (NOC) and GIS telecom observability dashboard.

---

## Features

- **NOC Observability Theme**: Deep obsidian dark mode, crisp typography, luminous cyan/emerald status badges, and responsive sidebar navigation.
- **GIS Leaflet Map**: OpenStreetMap tiles with custom SVG marker pins for serving cells, neighbor candidate cells, public towers, and GPS breadcrumb trail.
- **Interactive SVG Charts**: Real-time signal strength vs time graphs, RSRQ quality trends, technology distribution donuts, and operator average comparisons.
- **Full Mobile Responsiveness**: Seamlessly adapts to smartphones with a touch-friendly bottom navigation bar.
- **Demo Mode**: Built-in realistic multi-cell telecom simulation labeled with an unmistakable `DEMO DATA` badge.
